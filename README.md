# 上海四年级下语文复习网页

打开 `index.html` 即可使用。页面包含四阶段复习计划、28 天每日任务、八个单元复盘重点和本地 PDF 资料入口。

新增的“基础知识总表”按八个单元整合了生字拼音、会写字、词语听写、拼音易错点、多音字辨析和背诵默写清单。拼音会用红色标出平舌音、翘舌音、前鼻音和后鼻音；点击“打印默写表”可打印当前单元的生字、生词、拼音三类考核表。打印表中，生字表提供拼音提示，生词表提供每个词的拼音提示，拼音专项表提供汉字/词语让学生写拼音。古诗文全文可直接背默；现代课文、现代诗只列背诵篇目和段落提示，请以教材原文为准。

## iPad 本地使用

推荐用本地网页服务打开，不建议直接用 `file://`，这样 iPad 才能添加到主屏幕，并启用离线缓存。

1. 电脑和 iPad 连接同一个 Wi-Fi。
2. 在电脑终端进入本文件夹：
   ```bash
   cd "/Users/maclaw/Documents/New project/shanghai-grade4-chinese"
   python3 -m http.server 8123 --bind 0.0.0.0
   ```
3. 查看电脑局域网 IP。macOS 可在“系统设置 → Wi-Fi → 详细信息”里查看，通常类似 `192.168.1.23`。
4. iPad Safari 打开：
   ```text
   http://电脑局域网IP:8123/
   ```
5. Safari 点击分享按钮，选择“添加到主屏幕”。之后从 iPad 桌面图标打开，就像一个本地复习 App。

勾选状态保存在当前 iPad 的 Safari/主屏 Web App 本地数据里；只要不清除 Safari 网站数据，下次打开会保留。电脑需要保持开机，并继续运行上面的本地服务。
